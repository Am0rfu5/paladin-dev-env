**What changed:** a value that had been *derived* mechanically — "which position is authoritative"
was previously answered by running the precedence order over the corpus — becomes *chosen* and
recorded. D-02 simultaneously adds a new top tier to that order.

**Noun now primary:** the **ADR** (`.planning/decisions/NNNN-*.md`) is the primary authority for a
contested definition. The shipped tree is demoted to second — still the arbiter for everything no
ADR covers, but no longer the top of the order.

**Decision: `promote`.** The ADR tier is promoted to primary and the shipped tree demoted to a
detail of the "no ADR exists for this question" case, exactly as D-02 states. It is not added
alongside: an ADR that contradicts shipped code is an instruction to change the code (D-03's
`Code conformance: must change`), which is only coherent if the ADR outranks the tree rather than
sitting beside it.

**Invariant this earns (accepted, wired as an acceptance criterion in Task 1):** every restatement
of the precedence order in `.planning/PROJECT.md` carries the ADR tier — a later phase cannot
reintroduce the singular "shipped tree wins" assumption by finding a stale copy of the sentence.
