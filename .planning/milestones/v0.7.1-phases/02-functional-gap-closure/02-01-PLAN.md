<objective>
Establish the measured ground truth this phase is built on: one full `cargo test --workspace`
run with complete provenance, plus one executable re-proof per ROADMAP success criterion that
the Phase 1 ledger claims is already met.

Purpose: D-01 requires re-proof by execution, not citation. Three of Phase 2's five ROADMAP
success criteria were written before the Phase 1 ledger existed and their premises are stale —
SC1 names `test_auto_selects_campaign_for_workflow_keywords` as "fails today" and it passes.
This project's own repeated finding is that checkbox-and-citation evidence has been wrong in
both directions, so GAP-01, GAP-02, GAP-04 and GAP-05 close on a command that ran, on a commit
that is named, at a time that is recorded — not on the ledger's say-so.

Output: `.planning/phases/02-functional-gap-closure/02-test-baseline.md`, a raw-evidence record
following the shape of Phase 1's `01-coverage-measurement.md`.

**This plan edits no Rust source.** It runs first, alone in wave 1, so the baseline describes the
tree *before* Phase 2 changes it. The phase's tracer slice — the first production code task — is
task 1 of plan 02-02, per D-16 (the `ProviderCapabilities` change lands first because it has the
widest blast radius).
</objective>
