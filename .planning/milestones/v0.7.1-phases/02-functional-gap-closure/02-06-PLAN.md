<objective>
Turn test source that has never run into tests that run, and write the one provider-testing file
Epic 6 declared and never produced.

Purpose: `tests/unit/llm/` holds 25 test functions across three mockito-based files. Its own
`mod.rs` correctly declares all three — the omission is a single missing `pub mod llm;` line in
`tests/unit/mod.rs`, so none of them has ever been compiled into a test binary. Epic 6 task 6.0
is checked complete on the strength of tests that do not execute. That is precisely the
"believed working, actually not" shape this milestone closes, and the tests cover HTTP-level
paths (401, 429, streaming) the live 67 `paladin-llm` tests never reach — Phase 3's QUAL-02 names
`deepseek_adapter.rs` at 15% coverage, so deleting this suite would mean rewriting it there.
Separately, Epic 6 task 7.10's provider-switching integration test exists nowhere in the tree
under any name; D-09 puts it in scope as one of the genuinely-missing functional tests that
"working and tested" means for this milestone.

Output: a compiling, running LLM unit-test module and a new provider-switching integration test.
</objective>

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |

| T-02-21 | Spoofing | A checked-complete task backed by tests that never execute | high | mitigate | Wire the module into the `unit` target and require a passing run with a non-zero test count and zero ignored — a compiling module is explicitly not accepted as evidence, because the mockito hazard surfaces only at run time |
| T-02-22 | Tampering | Silent test deletion converting a real gap into an invisible one | high | mitigate | Removal is permitted only under the structural-breakage rule and every removal is recorded per test with the vanished behaviour named; an acceptance criterion forbids adding `#[ignore]` |
| T-02-23 | Tampering | Process-wide environment mutation from parallel test threads (the reason these calls are `unsafe`) | medium | mitigate | Every mutation is wrapped in an `unsafe` block with a call-site-specific safety justification, following the four existing in-repo precedents; interference is resolved by serialisation or restore-after, never by skipping the test |
