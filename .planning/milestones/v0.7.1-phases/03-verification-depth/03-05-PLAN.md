<objective>
Make `crates/paladin-storage/src/redis.rs` unit-testable without Docker, then give it its first unit
tests.

Purpose: `redis.rs` is 1,570 lines with zero `#[cfg(test)]` modules and 0.00% coverage — the single
largest genuine first-party coverage gap in the tree and the one QUAL-02 offender that survives
verification (D-03/D-05). Its only exercisers are testcontainers-based and require Docker, which is
absent from this environment. Its pure seams — key construction and (de)serialization — need no
server at all, but they cannot be reached today because they are declared as `&self` methods while
`RedisQueueAdapter::new()` blocks on a live `ConnectionManager` connection. The refactor is therefore
a prerequisite, not a nicety: without it a test module in this file stalls or errors on connection.

This is deliberately two tasks in strict order. A single "add tests to redis.rs" task fails.

Output: eight private helpers taking config instead of `&self`, and a `#[cfg(test)] mod tests` block
proving them.
</objective>
