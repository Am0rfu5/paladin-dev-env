## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| `github.com/RustSec/advisory-db` → local audit verdict | An external, versioned data source determines whether the gate is green; a stale or failed fetch produces a falsely-clean verdict |

| pushed `v*.*.*` tag → crates.io | Out of this plan's scope but named because the advisory posture is what a consumer of the published crates inherits |
