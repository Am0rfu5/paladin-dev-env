<objective>
Close CLOSE-02's Epic 14 cluster `8.0` — YAML & CLI Configuration Support for the autonomous
features.

Purpose: the four `--auto-plan` / `--auto-prompt` / `--dynamic-temp` / `--enable-handoffs` flags on
`AgentRunArgs` are declared and read by no code in the tree, and the CLI's `PaladinYamlConfig`
loader carries no `autonomous` field at all. The flags' own in-file comment promises "override
config file" against a config section that does not exist. This is one of exactly three clusters
Phase 5's block verdicts named as failing.

Output: an `autonomous` section on `PaladinYamlConfig` reusing `paladin-core`'s `AutonomousConfig`
directly (D-06), the four flags applied as additive overrides on top of that baseline in
`handle_agent_run` (D-05, D-07), and a commented-out `autonomous:` example in the generated agent
template.

**Executor note:** `.planning/config.json` sets `workflow.worktree_skip_hooks: true`. Do not
disable it — without it every commit cold-compiles the whole workspace inside the worktree.

**Spec-less probe fallback.** This plan carries edge-probe rows CLOSE-02/adjacency and
CLOSE-02/ordering, authored as `must_haves.truths` prefixed `[edge/...]` (2 of the phase's 8). One
prohibition survived Stage-2 precision and is authored descriptor-less above. **Canon-referral
breadcrumb (recorded, not minted):** "Path traversal and injection through the `--config` YAML load
path are canon — covered by `/gsd-secure-phase` and the Snyk code scan the project already mandates;
not minted here."
</objective>
