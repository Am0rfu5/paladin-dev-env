## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| CI runner → GitHub Actions marketplace | Third-party action code executes with repository-scoped credentials |
| CI runner → Codecov | An LCOV report and an upload token cross the boundary outbound |
| CI runner → github.com release assets | The pinned `actionlint` binary is downloaded and executed |

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|-----------|----------|-----------|----------|-------------|-----------------|
| T-15-SC | Tampering | Deprecated/unmaintained third-party actions in the workflow set | high | mitigate | Retire all four `actions-rs` references (archived vendor, no security patching since 2021) and all three `actions/cache@v3` references (deprecated cache-service API); replace only with the vendors already dominant in this repo (`dtolnay`, `actions`, `codecov`). Pin the `actionlint` download to a concrete release version rather than `latest`. No cargo/npm/pip package is installed by this plan, so the package-legitimacy gate does not apply. |
| T-15-02 | Information Disclosure | `codecov/codecov-action@v5` upload of `lcov.info` and `CODECOV_TOKEN` | medium | mitigate | The token is read from `secrets.CODECOV_TOKEN` and never echoed or written to a step output. `lcov.info` carries file paths and per-line hit counts only — no source text, no secrets.
