| Boundary | Description |
|----------|-------------|
| CI runner → GitHub Actions marketplace | `Swatinem/rust-cache@v2` executes on the runner with repository-scoped credentials and write access to the Actions cache |
| CI runner → crates.io | `cargo fetch --locked` pulls crate sources over the network into the job's cargo home |

| Repository tree → dependency gate | `deny.toml` and `SECURITY-EXCEPTIONS.md` are the surfaces that decide whether a known-bad dependency blocks a merge |
