<objective>
Prepare the three protection payloads so plan `15.1-08` has nothing left to decide except whether to
apply them. Three decisions land in these files.

**D-05** replaces the trunk ruleset's three-context required set with the set derived from the jobs
that actually exist — every job except the container build and the cluster smoke test. Those two are
excluded **by a recorded decision carrying a measurement**: the container build measured 3762 seconds
and is the entire run's critical path, because it builds two architectures with one under emulation.
Combined with the up-to-date-branch policy the committed payload already sets, requiring it would
serialise every merge behind an emulation run. Both jobs keep running on every push and pull request;
they simply stop standing between a green pipeline and the merge button.

**D-07** sets the required approving review count to zero and removes the always-on administrator
bypass from the trunk ruleset. The payload as committed is self-defeating: one collaborator, no
self-approval, so a review requirement of one is satisfiable only through the bypass — and that
bypass skips the required status checks too. Applying it unchanged would leave SC2's own diagnosis
true for the only active committer. A pull request stays mandatory; force-push and deletion stay
blocked; no second human is required.

**D-08b** extends protection to the release-branch ref class pre-emptively and, separately,
**retains** the bypass on the tag ruleset. That asymmetry is deliberate: the tag ruleset restricts
tag *creation* to bypass actors, so removing its bypass would make cutting any release impossible.

Purpose: SC2's payloads become correct before they become live.
Output: two edited ruleset files and one new one. **Nothing is applied here** — the live request is
plan `15.1-08`, behind its own blocking checkpoint, because it is an outward-facing change to a real
repository.

**Executor note:** `workflow.worktree_skip_hooks: true` — bypass the hook when committing. This plan
edits JSON only; run no `cargo` command and make no network call that writes.
</objective>
