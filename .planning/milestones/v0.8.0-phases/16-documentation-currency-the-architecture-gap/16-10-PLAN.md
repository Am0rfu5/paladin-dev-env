<objective>
Continue DOCS-03's `# Examples` half across the domain and orchestration crates: every enumerated
entry point in `crates/paladin-core/`, `crates/paladin-battalion/`, `crates/paladin-memory/` and
`crates/paladin-herald/` that the D-05 record marks as lacking an example gets one, and the examples
run.

Purpose: these four crates carry the Paladin, Battalion, Garrison and Herald surfaces — the domain
nouns a reader meets first. With the port traits documented in 16-09, these examples can show the
real composition path (build a Paladin, run a Battalion, render through a Herald) rather than an
isolated call.
Output: `# Examples` blocks on the enumerated entry points in those four crates, all passing
`cargo test --doc`.

**Discretion decision (carried from 16-09, unchanged):** default to **compile-and-run**; `no_run`
only where live I/O or an unavailable adapter makes it unavoidable, with the reason recorded per
example; never `ignore` or `text` for Rust code. ADR-0033 Finding 3 records 87 pre-existing
un-audited non-running fences — do not grow that pile silently.

**Note on `paladin-herald`:** plan 16-07 flipped this crate's crate-level missing-docs posture to
match its nine siblings, measured at zero new warnings (M-07). Re-run the doc gate after touching it
and confirm that is still true.

**Scope guards:** D-05 — work the enumeration, not a fresh interpretation. D-06 — plural heading on
entry points, non-enumerated sites untouched. D-08 — no workflow edits. D-00o — commit with
`--no-verify`; do not run a full-workspace `cargo test` for self-verification.
</objective>

## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| doc-comment source → published rustdoc + docs.rs | These examples are the first code a reader of the domain crates copies; a wrong one propagates. |
| doc examples → `cargo test --doc` | Doctests execute; an example constructing a real adapter would perform real I/O during a test run. |
| feature-gated types → default-feature doc build | An example built on a gated type breaks the default build unless it is gated the same way. |
