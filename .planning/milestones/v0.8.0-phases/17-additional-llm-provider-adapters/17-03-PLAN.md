<objective>
Expand the proven tracer slice to the three remaining OpenAI-compatible presets: **Qwen** (Alibaba
DashScope compatible-mode), **Grok** (xAI), and **Ollama** (self-hosted). Each is a thin preset over
the `CompatEngine` plan 17-01 built — `base_url`, credential env var, default model, curated
fallback model list, capabilities block, provider-name literal — and nothing else (D-05).

**Purpose:** D-01's build list is five named adapters. Three of them are pure preset work once the
core exists; that is the whole argument D-05 rests on, and this plan is where it either holds or
does not. **Ollama additionally matters out of proportion to its size:** it is the only provider in
the phase testable with no credential, so it is the phase's only end-to-end exercise of the shared
core against a real implementation of the protocol (D-15) — the Docker-gated Tier-2 suite that
exploits that lands in plan 17-07.

**Output:** `qwen/`, `grok/` and `ollama/` modules with mock-transport tests; three `paladin-llm`
Cargo features; three registry rows; three `lib.rs` declarations.

## Decisions resolved in this plan

- **DashScope region default (RESEARCH.md Pitfall 6 / Assumption A3) — DECIDED:
  `https://dashscope-intl.aliyuncs.com/compatible-mode/v1`,** overridable via `DASHSCOPE_BASE_URL`.
  DashScope publishes at least five regional base URLs and 17-CONTEXT.md's D-12 fixes only the env
  var name, not the region. The international endpoint is chosen as the most broadly reachable
  default; the override env var follows the identical pattern `DEEPSEEK_BASE_URL` and
  `ANTHROPIC_BASE_URL` already establish, so an operator in any other region reaches their endpoint
  with one variable and no code change. Record the rationale in the adapter's module rustdoc so the
  choice is discoverable at the point of use, not only in planning artifacts.
- **Ollama auth — DECIDED: send a fixed placeholder, do not make the header optional.** Ollama's own
  docs state the API key is "required but ignored". Making `Authorization` an `Option` in the shared
  engine forks the header-construction path for exactly one provider; sending the literal
  placeholder `"ollama"` keeps one code path for all five presets and matches the vendor's own
  documented example. This satisfies D-12's "none required" — no operator ever sets a credential
  variable for Ollama.
