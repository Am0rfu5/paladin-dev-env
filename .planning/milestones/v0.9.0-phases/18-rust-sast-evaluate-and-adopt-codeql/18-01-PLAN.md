## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| repository source → CodeQL extractor | First-party source crosses into a third-party analysis toolchain running with `security-events: write` |
| CodeQL run → GitHub code-scanning alert store | SARIF written into the platform's security surface; whatever lands there is what future readers treat as the assurance record |
| workflow YAML → trigger-policy register → ruleset | Three separate records of the same trigger and required-check facts; any disagreement between them is a silent gate failure |
