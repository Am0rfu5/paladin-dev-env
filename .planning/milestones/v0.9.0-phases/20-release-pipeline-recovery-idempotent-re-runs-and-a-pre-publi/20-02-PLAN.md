    `gh api repos/${GITHUB_REPOSITORY}/actions/workflows/ci.yml/runs` with `head_sha` set to the SHA

    authorisation, rate limiting — yields the status token `CI_LOOKUP_FAILED` and a non-zero exit;
    it is never reported as "no successful run" and never as a pass. No call added here may be given

<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| GitHub REST API response → gate verdict | A JSON body decides whether publishing may proceed |
| repo working tree changelogs → gate verdict | Files under version control decide the same |
| operator shell → gate script arguments | `--tag`, `--sha` and fixture paths are caller-supplied |

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|-----------|----------|-----------|----------|-------------|-----------------|
| T-20-06 | Spoofing | CI-conclusion clause | high | mitigate | Conclusion is read from a recorded run resolved by `head_sha`, never inferred from branch membership or from `verify-tag-source`; the deciding run is selected by a total ordering so the answer cannot depend on API response order |
| T-20-07 | Tampering | `gh api` response parsing | high | mitigate | Fields are extracted with `jq -e` so a missing or null `conclusion` is a loud failure; a non-2xx that is not the handled 404 becomes `CI_LOOKUP_FAILED` and fails the gate rather than degrading to a pass |
| T-20-08 | Information Disclosure | `gh`/`curl` calls carrying credentials | medium | mitigate | No redirect-following option is passed on any call, per `security.instructions.md`; asserted mechanically in Task 2's `<verify>` |
| T-20-09 | Elevation of Privilege | Gate skipped on the CI path | high | mitigate | `MISSING_SHA` makes a SHA-less run inside GitHub Actions a hard failure, so the CI-conclusion clause has no path to being silently absent where it matters |
| T-20-10 | Repudiation | Local pass mistaken for a full-gate pass | medium | mitigate | The offline report states explicitly that the CI-conclusion clause was not checked, rather than omitting it |
| T-20-SC | Tampering | npm/pip/cargo installs | high | mitigate | No package installs in this plan; if any appears, stop and run the Package Legitimacy Gate protocol first |
</threat_model>
