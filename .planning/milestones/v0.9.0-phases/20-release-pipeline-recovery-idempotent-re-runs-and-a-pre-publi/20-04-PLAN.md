<objective>
Make the strict, no-exemptions gate (D-09) satisfiable without an eleven-file manual chore: extend
the release tooling so the ten crate changelogs are finalized mechanically alongside the root one,
and run the consistency gate inside `make release` before the tag is pushed.

Purpose: today all ten crate changelogs sit at `## [Unreleased]` with no versioned section, so the
gate as specified would (correctly) fail every tag. D-09 refuses to create an exempted path for
prerelease tags — an exempted path is an untested path, and the D-14 rehearsal runs on a prerelease.
The way to keep the rule strict is to make satisfying it mechanical.

Output: `scripts/finalize-crate-changelogs.sh`, its regression harness, a `make release` that calls
it and then gates on `check-release-consistency`, and a `release.toml` comment recording why
cargo-release's replacement mechanism is not the carrier.
</objective>

## Trust Boundaries

|----------|-------------|
| operator-supplied `VERSION` → file rewriting | A version string drives an in-place edit of eleven tracked files |
| local release flow → public tag push | `make release` pushes a tag that triggers a real publish |

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|-----------|----------|-----------|----------|-------------|-----------------|
| T-20-15 | Tampering | In-place changelog rewriting | medium | mitigate | The script writes only at a recognised anchor and only when no section for that version exists; an unexpected file shape is a named failure that leaves the file untouched, so a malformed version or an edited changelog cannot corrupt tracked content |
| T-20-16 | Elevation of Privilege | Tag pushed for an unverified tree | high | mitigate | The consistency gate runs between the finalize step and `git tag`/`git push`, so the local flow cannot publish a tag whose tree the gate rejects. The CI job remains authoritative for the CI-conclusion clause, and the Makefile comment says so |
| T-20-SC | Tampering | npm/pip/cargo installs | high | mitigate | No package installs in this plan; `cargo-release` is an existing preflight dependency of `make release`, not a new one. If any install appears, stop and run the Package Legitimacy Gate protocol first |
