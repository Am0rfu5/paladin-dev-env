## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| mock Paladin output → Herald rendering | Test-controlled output text and Paladin names cross into the three rendered formats, exercising the same path operator-facing output takes |
| injected failure → partial result | A deliberately-failed node's error text crosses into the rendered failure section |

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|-----------|----------|-----------|----------|-------------|-----------------|
| T-02-17 | Spoofing | A test that appears to prove end-to-end rendering while proving only formatter self-consistency | high | mitigate | The test drives a real `FormationExecutionService`; an acceptance criterion greps the file to prove no `BattalionResult` literal is constructed, and every asserted value is derived from the mocks' own configured outputs and token counts |
| T-02-18 | Tampering | Assertions that pass on any output because they only check substring presence | medium | mitigate | Execution order is asserted positionally against the JSON per-Paladin array, and the aggregate token total is computed in the test from the mocks' counts so a change to one mock changes the expected value |
| T-02-19 | Information Disclosure | Injected failure text carrying a realistic-looking credential into a committed test fixture | low | mitigate | The injected failure uses a plainly synthetic error string; no API key, token or credential-shaped literal is placed in the fixture. This repository has a recorded historical incident of a plaintext key committed in a document |
| T-02-20 | Denial of Service | A hanging integration test blocking the suite | low | mitigate | The test uses in-process mocks with no network or filesystem dependency, and drives the same service path the existing `herald_integration_test.rs` analog already runs inside the standard suite timeout |
| T-02-SC | Tampering | npm/pip/cargo installs | high | mitigate | No package-manager install and no new dependency; `tokio`, `serde_json` and `uuid` are already workspace dependencies |
