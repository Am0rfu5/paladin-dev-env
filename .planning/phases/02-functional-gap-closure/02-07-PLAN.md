<objective>
Unblock the CLI test cluster by supplying the one file its 1,895 lines of already-written tests
have been waiting on, then make those tests pass.

Purpose: Epic 9 tasks 13.4-13.6 are recorded in the Phase 1 ledger as genuinely outstanding —
"the blocker is gone, the test itself was never written". Direct reading of the tree corrects
that: the tests *are* written. `tests/cli/{formation,phalanx,paladin}_execution_test.rs`,
`error_handling_test.rs` and `tool_integration_test.rs` exist, use current APIs, and import
mocks from a `crate::helpers` module that does not exist inside the `cli` test target — because
`cli` is its own `[[test]]` target rooted at `tests/cli/mod.rs` and therefore does not
automatically see the sibling `tests/helpers/` directory the `unit` and `lib` targets use. All
five `mod` declarations sit commented out in the barrel with a note naming the missing helpers
module. The fix is one shim file and five uncommented lines, plus whatever the compiler and the
test run then surface.

Output: a `cli` test target that compiles and runs the Paladin, Formation and Phalanx execution
suites under the `cli` feature.
</objective>
