1. **The tag is created locally and left unpushed**, rather than discharging SC1 with a documented
   tag command alone. D-03 recommends this; a local annotated tag is one `git tag -d` away from
   undone, and having it exist makes "the git tag agrees with the manifests" a checkable fact rather
   than an intention.

   provenance note**, not renamed. It refers to real historical `.project/`-era milestone numbering;
   rewriting shipped release-note prose to avoid a misreading is more destructive than annotating
   it. The note states that it is not a GSD `.planning/phases/` phase number.

## Flagged assumption (unresolved edge probe)

The deterministic edge probe classified REL-01 as `unclassified` and it stays **unresolved** — it is
carried here as an explicit assumption rather than silently dropped or auto-backstopped. The
assumption is that "version metadata tells one story" has no hidden boundary or ordering case beyond
the ones enumerated in `must_haves.truths` above: one version string across twelve manifests plus
every internal pin, one dated CHANGELOG heading per released version, and one tag. If a reviewer can
name a version surface not in that list — release notes shipped outside `CHANGELOG.md`, a version
baked into a Docker label, a version asserted in documentation — it is an unenumerated edge and
belongs in a gap-closure plan, not in a silent pass.
