`--exclude paladin-ports`, in one commit, and prove the ~25 port traits' rustdoc examples compile
and run.

`cargo test --offline -p paladin-ports --doc` was run: **96 passed, 0 failed, 94 ignored**; the
manifest was restored and `git status --short` confirmed clean. The blocker the comment describes
was already fixed by whoever rewrote the examples to `paladin_ports::` / `paladin_core::` paths —
nobody removed the flag afterwards. DEBT-03 is therefore a two-line diff plus a verification, and
D-10's example-repair rules survive only as a contingency if the workspace-level run surfaces
something the crate-level run did not.

Output: doctests executing for `paladin-ports`, in CI and locally, with the measurement recorded.
</objective>
