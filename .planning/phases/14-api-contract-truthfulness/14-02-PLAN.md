<objective>
Close WEB-03's remaining residue and Phase 13's first hand-off item — both are "pin a literal against
its source of truth" fixes with the same shape, both are independent of WEB-01's rename, and both are
verified small.

D-12: the OpenAI adapter declares `supports_function_calling: true` while hard-coding
`function_call: None` in its response builder — the last asymmetric flag after Phase 2 plan 02-02
already flipped `supports_tool_calling` honest on all three adapters. The flag flips, and the existing
correspondence test is **extended** (not replaced, not forked) so both flags are pinned by the same
test and cannot drift apart independently again.

D-15(a): `crates/doc-examples/src/sidecar.rs` teaches an unversioned agent route through an mdBook
`{{#include}}`, contradicting ADR-0037's `/v1` surface. The literal is corrected and paired with an
assertion tying it to `paladin_web::agent_controller::API_V1_PREFIX` — because `cargo check` cannot
catch an opaque string literal, and without the assertion the drift returns on the next prefix change.
Landing this moves threat **T-13-20** from accepted residual risk **AR-13-01** to closed.

Purpose: make a declared capability match the behaviour behind it, and make a published example match
the route it documents.
Output: one flipped flag, one extended correspondence test, one corrected route literal, one new
drift-guard assertion.
</objective>
