## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| CI run output → the permanent record | A number read out of a job log becomes a published gate value every later run is judged against |
| Human checkpoint reply → ADR text | A figure supplied in conversation is transcribed into a decision record |

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|-----------|----------|-----------|----------|-------------|-----------------|
| T-15-07 | Repudiation | The recorded coverage figure not traceable to the run that produced it | medium | mitigate | D-00e's evidence bar is enforced as an acceptance criterion: the amendment must carry the exact command, the commit SHA, the run URL and the date. A figure without provenance fails the criteria and the plan does not close. |
| T-15-08 | Tampering | A transcription error or a rounded figure silently shifting the published floor | medium | mitigate | The figure is copied byte-identically from the job log, never re-typed or rounded (D-00e); Task 3 reads the floor integer from the ADR rather than recomputing it; a machine check asserts the same integer appears in exactly one place in each of the three files and that all three agree. |
| T-15-09 | Elevation of Privilege | A gate that silently does not run — a fork-PR Codecov upload failing while appearing to be the gate | high | mitigate | The gate is `cargo llvm-cov --fail-under-lines` executing inside the workflow, where a failure is a job failure. Codecov is configured non-blocking (`informational: true`, no `fail_ci_if_error`), so no path exists where an absent upload is mistaken for a passed gate. |
| T-15-10 | Information Disclosure | The `gh run view --log` capture in the checkpoint surfacing secrets from the job log | low | accept | GitHub Actions masks registered secrets in logs, the coverage job consumes only the ephemeral service-container credentials already public in the workflow file, and the checkpoint instructions grep for coverage lines rather than dumping the whole log. |
</threat_model>
