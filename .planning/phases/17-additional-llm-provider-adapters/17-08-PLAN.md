<objective>
Close PROV-04's second half: **the advertised surface matches the shipped one.** `paladin-llm`'s
`Cargo.toml` description and keywords, the crate README, the configuration example and the
configuration documentation must name exactly the providers that exist — no more, no fewer — so this
phase does not manufacture the same documentation-currency debt DOCS-01 exists to close.

goes red when a crate's public surface changes without the baseline being regenerated — that is the
guard DEBT-01 repaired and this phase adds a lot of public types.

records it as a manual-only verification: a human reads the three side by side. This plan does the
mechanical work and then puts that reading in front of a human.

**Output:** updated crate metadata, README, config example, config docs, a regenerated exports
baseline, and a human sign-off on the currency check.
