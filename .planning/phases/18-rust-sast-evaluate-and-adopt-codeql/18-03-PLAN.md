<objective>
Run the probe, read what actually came back, and settle whether CodeQL qualifies — with the
coverage evidence recorded beside the finding count so the two can never be confused.

The Snyk failure was that "analysed 0 files" and "found 0 issues" look identical in a report.
This plan makes them different data. Before any finding count is interpreted, the fixture's own
files must be confirmed present in the source set CodeQL extracted; only then does a per-class
finding table mean anything.

Both outcomes are deliverables. A zero-finding result disqualifies the tool and ends the phase in
its recorded-verdict branch, which is a success, not a failure.

Purpose: SAST-01 is settled here, and every plan after this one is conditional on the verdict.
Output: `18-CODEQL-EVIDENCE.md` carrying the probe result, the coverage evidence, the answer to
the feature-coverage question, and an explicit verdict.
</objective>
